# VISTARA — Stadium Ticket Booking System

A front end web development project by Ruchir, Sarvaghya, Sarthak.

Built with HTML and CSS.

## Pages

- `index.html` — Home page with hero, competition tiles, promise section
- `fixtures.html` — Upcoming ISL fixtures with filter bar
- `booking.html` — Book a match, choose a block, view stadium
- `seats.html` — Pick exact seats, live price tally with GST
- `checkout.html` — Enter details and pay

## How to run

Open `index.html` directly in Chrome. No server needed.

## Features

- Responsive navbar with active page highlighting
- Full-screen hero section with stadium background photo and dark overlay
- Disabled search box — display only, intentional design choice to show future search functionality
- ISL and IPL competition tiles with diagonal stripe pattern using CSS gradients
- Fixtures table with When, Sort by and Price range filter dropdowns
- Match info header with kick-off time, ground, capacity and starting price
- 4-step booking progress bar — Choose block, Pick seats, Pay, Get tickets
- Block selection cards with coloured dot indicators and quantity arrow buttons
- Static JLN Stadium seating plan with colour-coded block legend
- View in 3D button — intentionally non-functional, reserved for a planned future feature
- Seat grid with available, sold and selected states
- Live tally bar with GST at 28% calculated in real time
- Checkout form with delivery options — mobile tickets, print at home, collect at ground
- Order summary panel with full GST breakdown
- Pay button — non-functional by design, no real payment processing
